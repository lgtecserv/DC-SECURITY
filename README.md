## 🌐 Publicação na Vercel

O projeto está 100% configurado para a Vercel com App Router, TypeScript e Tailwind CSS.

### Opção 1: Via Vercel CLI
```bash
npx vercel
```

### Opção 2: Via GitHub / GitLab / Bitbucket
1. Envie este repositório para o seu GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: website institucional DC SECURE GROUP"
   git remote add origin https://github.com/seu-usuario/dc-security.git
   git push -u origin main
   ```
2. No painel da [Vercel](https://vercel.com):
   - Clique em **"Add New Project"**
   - Importe o repositório `dc-security`
   - O framework **Next.js** será detectado automaticamente com comando de build `npm run build`
   - Clique em **"Deploy"**
